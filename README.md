# Home Lab Infrastructure

## Project Overview

This project documents the design, implementation, and administration of my personal home lab environment.

The goal is to develop and demonstrate practical skills in network administration, virtualization, infrastructure security, and storage management.

## Project Objectives

- Deploy a dedicated network firewall
- Configure network segmentation using VLANs
- Implement centralized file storage and private cloud services
- Enable secure remote access to home network resources
- Configure automated backups for personal devices
- Document system configurations, troubleshooting, and maintenance procedures

## Hardware

- 3 Supermicro servers
- Cisco network switch
- Intel Core i5-6500 mini PC with 8 GB RAM and 256 GB storage
- Additional storage drives (planned)

## Project Status

**In Progress**

Initial hardware inspection has begun. The firewall operating system has been installed on the mini PC, with network interface configuration pending.

## Documentation

This repository will contain network diagrams, equipment specifications, implementation guides, configuration examples, and troubleshooting records.
